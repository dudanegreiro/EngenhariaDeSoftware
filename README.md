# EngenhariaDeSoftware- 
O EventFy é uma plataforma web que conecta organizadores de eventos a prestadores de serviços e fornecedores de estruturas necessárias para a realização de um evento. O sistema resolve o problema da dispersão: hoje, um organizador precisa buscar separadamente garçons, seguranças, produtores, baristas, atendentes, som, transporte, entretenimento e espaços em canais diferentes. O EventFy centraliza essa busca e a gestão das reservas em um único lugar.
O sistema trabalha com dois grandes grupos de itens alugáveis:
●	Serviços de pessoas: garçom, segurança, produtor, barista, atendente.
●	Estruturas e serviços de apoio: som, automotivo, entretenimento, espaços.
Esses dois grupos são modelados como categorias dentro de um catálogo único de itens alugáveis, o que simplifica o banco de dados e facilita a extensão do sistema no futuro.
